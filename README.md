# Big Data E-Learning

Big Data E-Learning is a group class project for a university Programming Methods and Practice course. The goal is to create an interactive educational website that teaches the fundamentals of Big Data.

## Project Purpose

This website will help students learn Big Data concepts through short lessons, interactive activities, knowledge checks, and a final assessment.

The current version is only a foundation scaffold. It is intentionally simple so the team can build on it during the project.

## Technologies

- HTML
- CSS
- Vanilla JavaScript

This project does not use a backend, database, or frontend framework.

## How to Run Locally

Open `index.html` in a web browser.

No installation is required.

## Team Roles

- Project Manager / CEO + Developer: manages GitHub and integrates code
- CTO + Writer: creates lesson content and quiz material
- CIO + Tester: tests pages, links, layout, and behavior
- Designer + UI Design / Art: improves layouts and visual identity
- Audio / Music + Multimedia: creates or collects audio and media assets
- Audio / Music + Multimedia: supports multimedia features

## Suggested Team Workflow

1. Pull the latest changes before working.
2. Work on one page or feature at a time.
3. Test changes locally in the browser.
4. Commit with a clear message.
5. Push changes to GitHub.
6. Tell the team what changed.
