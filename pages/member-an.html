About My Role

My role is Audio/Music and Multimedia. This part of the project is about making the website feel more interactive and less like a plain document. Big Data can sound complicated at first, so media can help make the topic easier to approach. That could mean short audio introductions, simple sound effects, small visuals, or other media that supports the lessons and activities.

One strength I can bring is helping the site feel more alive. Audio and multimedia can make a quiz or activity feel more finished, especially if the learner gets feedback after answering a question. A weakness I need to think about is that media can become distracting if there is too much of it. For this project, the best media should be useful and simple. It should help explain the idea, not take attention away from the lesson.

In the prototype, my work can start with planning what kind of media belongs in each module and where those files should go. Later, I can help add audio clips, icons, or short media examples to the activity areas. My goal is to make the learning experience more memorable while still keeping the website lightweight enough to run locally and work on GitHub Pages.
