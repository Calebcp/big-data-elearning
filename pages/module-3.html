Module 3

Types and Sources of Data

Compare common data types and practice sorting examples by structure.

Learning Objectives

  • Compare structured, semi-structured, and unstructured data.
  • Recognize common sources of data.
  • Classify data examples into the correct type.

Lesson Content

Big Data can come in different forms. Structured data is organized in a clear format, usually rows and columns. Semi-structured data has some organization, but it does not always fit neatly into a table. Unstructured data has no fixed table format and may need extra processing before it can be analyzed.

Structured

Spreadsheets, sales records, attendance tables, bank transactions.

Semi-structured

JSON files, emails, logs, web data with tags or labels.

Unstructured

Photos, videos, voice recordings, documents, social media posts.

A single project can use more than one type. For example, an online store may store order information in tables, product descriptions as text, and customer photos or reviews as unstructured data.

Data sources are the places where information begins. Common sources include websites, mobile apps, sensors, surveys, purchases, machines, public records, and social media posts. Before analysis begins, teams should understand where the data came from, who created it, and whether it is complete enough to answer the question.

The type of data affects the tools used to process it. Structured data can often be filtered or counted quickly. Semi-structured data may need parsing, because useful details are stored inside tags, labels, or key-value pairs. Unstructured data often needs extra steps such as image recognition, speech-to-text, or text analysis before patterns can be found.

Case Study: Online Learning Platform

A learning website can collect quiz scores as structured data, clickstream logs as semi-structured data, and recorded student presentations as unstructured data. Combining these sources can help teachers see which topics students understand and where extra support is needed.

Interactive Activity

Classify each example by the way the data is organized.

Class attendance spreadsheet with rows and columns

Structured data follows a fixed format, such as rows and columns.

Website activity log with timestamps, page names, and labels

Semi-structured data has organization, but it does not always fit a simple table.

Video from a traffic camera

Video is unstructured because it must be processed before a computer can easily analyze it.

Knowledge Check

Question: Is a photo usually structured, semi-structured, or unstructured data?

Answer: Unstructured data.
