About My Role

My role is Creative Leader and Designer, so I am thinking about how the website looks and how it feels to use. A Big Data learning site could easily become dry if it is only text, so design matters. I want the pages to feel clean, modern, and easy to scan. That means paying attention to color, spacing, cards, buttons, images, and how students move from one section to the next.

One strength I can bring is creative direction. I can help decide what kind of style fits the project and how to make the site look more like an e-learning platform. One weakness I need to be careful about is over-designing. Since this is a class project using basic web tools, the design should not become so complicated that the team cannot maintain it. Simple and consistent is better than flashy but confusing.

For this prototype, I want to improve the team page, module cards, lesson sections, and activity areas so they feel connected. Later, I can also help choose icons, diagrams, and visual examples for Big Data concepts like the 5 Vs or the data pipeline. My goal is for the website to look organized enough for a presentation but still friendly enough that students would actually want to click through it.
