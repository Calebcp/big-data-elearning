Module 4

How Big Data Works

Placeholder lesson page for a simple Big Data pipeline.

Learning Objectives

  • Describe the stages of a basic Big Data pipeline.
  • Explain the purpose of collecting, storing, processing, analyzing, and using data.
  • Connect pipeline stages to a real-world example.

Lesson Content

Big Data usually moves through a pipeline. A pipeline is a series of steps that turns raw data into something useful. The basic version is: collect, store, process, analyze, and use.

  1. Collect: Gather data from apps, sensors, websites, or records.
  2. Store: Keep the data somewhere organized and accessible.
  3. Process: Clean, combine, or prepare the data.
  4. Analyze: Look for patterns, trends, or answers.
  5. Use: Apply the results to make a decision or improve a service.

A map app is a good example. It collects location and traffic data, stores it, processes current road conditions, analyzes possible routes, and uses the result to recommend a faster path.
