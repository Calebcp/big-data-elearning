Module 4

How Big Data Works

Follow the basic pipeline from data collection to real-world use.

Learning Objectives

  • Describe the stages of a basic Big Data pipeline.
  • Explain the purpose of collecting, storing, processing, analyzing, and using data.
  • Connect pipeline stages to a real-world example.

Lesson Content

Big Data usually moves through a pipeline. A pipeline is a series of steps that turns raw data into something useful. The basic version is: collect, store, process, analyze, and use.

  1. Collect: Gather data from apps, sensors, websites, or records.
  2. Store: Keep the data somewhere organized and accessible.
  3. Process: Clean, combine, or prepare the data.
  4. Analyze: Look for patterns, trends, or answers.
  5. Use: Apply the results to make a decision or improve a service.

A map app is a good example. It collects location and traffic data, stores it, processes current road conditions, analyzes possible routes, and uses the result to recommend a faster path.

A real pipeline also includes decisions about quality and timing. Data may need to be checked for missing values, duplicated records, or errors before it can be trusted. Some pipelines run in batches, such as a report generated every night. Others run in real time, such as fraud detection during an online payment.

The final step is action. A chart, alert, recommendation, or prediction only matters if someone uses it responsibly. Good Big Data systems connect technical work to a clear goal, such as saving time, reducing risk, improving learning, or helping users make better choices.

Case Study: Streaming Service Recommendation

A streaming service collects watch history, stores account activity, processes repeated views and ratings, analyzes patterns between similar viewers, and uses the result to recommend shows. The pipeline must update often because viewer interests change over time.

Interactive Activity

Match each action to the pipeline stage it belongs to.

Remove duplicate app clicks before counting user behavior.

Processing prepares raw data by cleaning, combining, or organizing it.

Show a warning when traffic is expected to be heavy.

Using data means applying the result to a decision, message, or action.

Save sensor readings in a database so they can be searched later.

Storage keeps data organized and available for later processing or analysis.

Knowledge Check

Question: Why does data usually need to be processed before analysis?

Answer idea: Raw data can be messy, incomplete, duplicated, or hard to compare.
