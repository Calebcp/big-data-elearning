About My Role

My role is Audio/Music and Multimedia. I am helping with the parts of the website that can make the Big Data topic feel more interesting and easier to remember. Since the project is an e-learning prototype, it should not only have text and buttons. It should also have visual and media ideas that support the learning path. This could include sounds, small graphics, images, or short clips if they fit the lesson.

One strength I can bring is thinking about the feeling of the site. For example, when a user completes an activity, a small sound or visual response can make the action feel more satisfying. A weakness I need to avoid is adding media just because it looks cool. The media should match the topic and should not make the page slow or confusing. Since we are building with simple HTML, CSS, and JavaScript, the media also has to stay easy to manage.

For this first version, I can help organize media files and plan where multimedia should appear in the modules. Later, I can work with the designer and writer to make sure images, sounds, and any video clips actually fit the lesson content. My goal is to help the website feel more complete while still keeping it clean, readable, and appropriate for a class project.
