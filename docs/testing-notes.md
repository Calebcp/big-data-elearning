# Big Data E-Learning Testing Notes

This document is for the CIO/Tester. Use it as a checklist when reviewing the website.

## Navigation

- Home link opens `index.html`.
- Module cards open the correct module pages.
- Previous and next buttons move through the course in the correct order.
- Final Quiz link opens `pages/final-quiz.html`.
- Navigation works from both the homepage and pages inside the `pages/` folder.

## Links

- No broken links.
- Asset links load correctly after images, audio, or video are added.
- Documentation links open correctly.

## Responsive Layout

- Homepage looks good on laptop/desktop screens.
- Homepage looks good on phone-sized screens.
- Module pages stack cleanly on smaller screens.
- Text does not overlap buttons, cards, or navigation.
- Mobile navigation toggle opens and closes the menu.

## Buttons and Interactions

- Buttons are easy to see and click.
- Buttons have clear labels.
- Future activity buttons respond correctly.
- Future quiz answer buttons show clear feedback.
- Restart quiz button resets the quiz once quiz logic is added.

## Quiz and Activity Behavior

- Questions display in the correct order.
- Correct answers increase the score.
- Incorrect answers show useful feedback.
- Question counter updates correctly.
- Final results display at the end.
- Progress indicators update correctly once progress logic is added.

## Spelling and Content

- Module titles are spelled correctly.
- Big Data terms are used consistently.
- Examples are clear for beginner learners.
- Placeholder text is removed before final submission.

## Browser Testing

- Test in Chrome.
- Test in Safari.
- Test in Firefox if available.
- Confirm the website runs locally by opening `index.html`.
- Confirm the website is compatible with GitHub Pages.

## Broken Media and Assets

- Images are placed in `assets/images/`.
- Icons are placed in `assets/icons/`.
- Audio files are placed in `assets/audio/`.
- Video files are placed in `assets/video/`.
- Media files have reasonable file sizes for web use.
- All media has appropriate captions, labels, or alt text.
